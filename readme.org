My website is hosted on [[https://neocities.org/][Neocities]] and built with [[https://jekyllrb.com/][Jekyll]].

I use [[https://github.com/ai-robots-txt/ai.robots.txt][this]] repository for my ~robots.txt~.

I use the [[https://github.com/neocities/neocities-ruby][Neocities gem]] to help deploy, which is just:
#+BEGIN_SRC sh
# Build to _site
jekyll build

# Recursively push uploaded files to Neocities
neocities push _site
#+END_SRC
